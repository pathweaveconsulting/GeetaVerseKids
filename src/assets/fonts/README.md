# Fonts

Fredoka and Quicksand (variable, weights 300–700), Latin and Latin Extended
subsets, from the `@fontsource-variable/fredoka` and
`@fontsource-variable/quicksand` packages, version 5.3.0. Both are licensed
under the SIL Open Font License 1.1 (see the `OFL-*.txt` files).

They are self-hosted so the app makes no requests to Google or any other
third party. `src/index.css` declares them with `@font-face`.
